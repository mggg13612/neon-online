# NEON STRIKER ONLINE
Node.js 20 이상. `npm install` 후 `npm start`. 브라우저에서 http://localhost:3000 접속.
공개 배포: GitHub에 이 폴더의 파일을 올리고 Render Web Service에서 저장소를 연결. Build Command: npm install, Start Command: npm start. PORT는 자동 사용. 공개 HTTPS 주소를 두 휴대폰에서 열고 방 생성/입장. 무료 플랜 제공 여부 및 제한은 배포 시 확인.
방은 서버 메모리에만 저장되며 재시작/연결 종료 시 사라집니다. 단일 서버 인스턴스 사용. 인증, 재접속 복구, 부정행위 방지, 대규모 트래픽 대응은 미구현. H 아이템은 살아 있는 팀원이 획득하면 쓰러진 팀원을 우선 부활시킵니다.
